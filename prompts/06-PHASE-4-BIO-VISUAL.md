## ۳. بخش ب — لایهٔ بصری جسور

### ۳.۱ ساختار
```
web/src/visuals/
├── scenes/            # هر صحنه یک ماژول، همه dynamic import
│   ├── HeroSystem/    # ⭐ امضای بصری — جایگزین NeuralNetwork3D فعلی
│   ├── SignalFlow/
│   └── DataLattice/
├── primitives/        # ذرات، خطوط، گرید، نور — مشترک
├── TierScene.tsx      # ⭐ wrapper اجباری: tier + viewport + fallback + reduced-motion
└── fallbacks/         # SVG/PNG از پیش رندرشده در CI
```

### ۳.۲ `<TierScene>` — wrapper اجباری
**هیچ صحنه‌ای بدون این wrapper رندر نمی‌شود.** یک rule eslint این را enforce می‌کند.

```tsx
<TierScene
  scene="HeroSystem"
  fallback={<HeroSystemStatic />}   // اجباری
  minTier="balanced"                 // زیر این سطح، فقط fallback
  lazy                                 // dynamic import
  pauseOffscreen                       // IntersectionObserver
/>
```

وظایف: خواندن tier از فاز ۰ · dynamic import · IntersectionObserver (شروع/توقف) ·
cap کردن DPR · cap کردن فریم در `balanced` · احترام به `reduced-motion` ·
رندر fallback در `low-power` یا نبود WebGL.

### ۳.۳ قوانین سخت (همه تست‌شدنی)

| # | قانون | enforce |
|---|---|---|
| 1 | `three`/`fiber`/`drei` **هرگز** در bundle اولیه | `bundle-budget` در CI |
| 2 | هر صحنه یک fallback از پیش رندرشده دارد | بررسی وجود فایل در `fallbacks/` |
| 3 | هیچ صحنه‌ای قبل از viewport شروع نمی‌شود | تست با mock IntersectionObserver |
| 4 | DPR ≤ ۲ (و = ۱ در `balanced`) | تست |
| 5 | در `low-power` **صفر** WebGL | تست: mock `hardwareConcurrency=2` → assert نبود canvas |
| 6 | هیچ انیمیشنی `height`/`width` ظرف را تغییر نمی‌دهد | بررسی CLS در Lighthouse CI |
| 7 | خارج از viewport، رندرloop متوقف می‌شود | تست |

### ۳.۴ صحنهٔ امضا (`HeroSystem`)
جایگزین `NeuralNetwork3D` فعلی (که فقط در `Hero.tsx` استفاده می‌شود).
باید **معنادار** باشد، نه تزئینی: گره‌ها = پنج توان تیم، یال‌ها = چطور ترکیب می‌شوند،
و **کلیک روی هر گره به artifact زندهٔ همان توان می‌رود** (G1 — نمایش، نه گفته).

⚠️ اگر صحنه نمی‌تواند معنادار باشد، **SVG تعاملی ساده بهتر از WebGL تزئینی است.**
«no gratuitous 3D» از v1 حفظ می‌شود — جسارت باید **هدفمند** باشد، نه پرحجم.

### ۳.۵ بودجه
- روت‌های اصلی همچنان **≤ ۲۰۰ KB gzip** اولیه. صحنه‌ها lazy هستند پس این نباید بشکند.
- روت‌های `/tools/*` و `/lab/*` ≤ ۳۵۰ KB.
- Lighthouse موبایل روی روت‌های اصلی: Perf ≥ ۹۰. ⚠️ **در `low-power` اندازه‌گیری شود** —
  چون آن حالت، حالت پیش‌فرض دستگاه‌های ضعیف است و کاربران واقعی آن را می‌بینند.
