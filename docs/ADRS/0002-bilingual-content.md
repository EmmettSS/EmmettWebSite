# ADR-002 — مدل محتوای دوزبانه

**وضعیت:** پذیرفته‌شده · ۲۰۲۶-۱۰-۰۱

## زمینه
فارسی زبان پیش‌فرض است و متن‌های بازاریابی dev-owned با محتوای عملیاتی CMS تفکیک می‌شوند.
## تصمیم
locale از URL (`/fa/`, `/en/`) می‌آید؛ Persian fallback اصلی است. محتوای DB فیلدهای `_fa` و `_en`، شناسهٔ slug لاتین یکتا و `slug_fa` اختیاری دارد. انتشار نیازمند عنوان و متن فارسی است؛ انگلیسی خالی در API fallback فارسی خواهد بود. پول به integer تومان و زمان‌ها UTC/aware ذخیره می‌شوند؛ UI با تقویم `Asia/Tehran` نمایش می‌دهد.
## پیامدها
برابری copy در CI و completeness در admin لازم است. برای پیوند معادل زبانی hreflang باید canonicalهای هر دو locale پایدار باشند.
