# زبان و قالب محلی‌سازی

- URL تعیین‌کنندهٔ زبان است؛ `/` و unknown route به `/fa` هدایت می‌شوند.
- فارسی RTL است؛ English LTR. سند HTML از `LanguageProvider` به‌روزرسانی می‌شود.
- `web/src/content/site.ts` محتوای UI دارای parity check است؛ `pnpm --filter @emmett/web content:check` با حذف کلید fail می‌شود.
- تاریخ‌های display با Intl Persian calendar و `Asia/Tehran` در `lib/jalali.ts`؛ ذخیرهٔ backend UTC aware.
- واحد پول integer تومان، نه float؛ utilities در `lib/toman.ts`.
- محتوای DB فارسی‌محور و slugs ASCII پایدار است. نقص copy انگلیسی باید به‌صورت warning/review حل شود، نه 500.
