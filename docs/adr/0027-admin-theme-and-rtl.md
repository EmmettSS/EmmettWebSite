# ADR-0027: تم اختصاصی ادمین، برند امیت و لایهٔ RTL

## ۱. زمینه

پنل مدیریت تا پایان فاز ۵ روی **Django Admin پیش‌فرض** بود: بدون برند، بدون جهت راست‌به‌چپِ
واقعی (چیدمان LTR با متن فارسی)، بدون داشبورد و بدون دارایی استاتیک اختصاصی. معیار پذیرش
فاز ۶ صریح است: «Admin آماده در سطح SaaS» با تم امیت (`#5b62e0` / `#1fae6e`)، لوگو، فونت
و RTL بی‌عیب — بدون اسکرول افقی در هیچ صفحه‌ای (جدول، فیلتر، inline، select2) و در همان
حال بدون شکستن چیدمان LTR در زبان انگلیسی.

محدودیت‌های محیط هدف (هاست اشتراکی cPanel) هم تعیین‌کننده است: بدون Node در runtime،
بدون CDN در دسترس (شبکهٔ هدف ممکن است دسترسی به CDNهای خارجی نداشته باشد)، و بدون
افزودن build step یا وابستگی سنگین (قانون ۶).

## ۲. گزینه‌ها

| گزینه | مزیت | دلیل رد/پذیرش |
|---|---|---|
| A. Unfold | ظاهر مدرن، Tailwind‑based | پشتیبانی رسمی RTL ندارد (issue #78 بسته‌شده با «not planned»)؛ نیازمند بازنویسی قالب‌ها و Tailwind build در بک‌اند |
| B. Django Admin پیش‌فرض + override قالب | بدون وابستگی | فاصلهٔ زیادی با معیار پذیرش (داشبورد، UI Customiser، Select2، تب‌ها) دارد و کار دستی آن چند برابر Jazzmin است |
| C. Jazzmin + لایهٔ RTL/برند اختصاصی (انتخاب‌شده) | UI آمادهٔ AdminLTE 3.2/Bootstrap 5، Select2، modal، UI Customiser؛ RTL با CSS اسکوپ‌شده در سطح خودمان | لایهٔ RTL باید خودمان نوشته شود، اما کاملاً قابل تست است (ADR-0028/تست‌های فاز ۶) |
| D. ساخت پنل کامل با Next.js | کنترل کامل | خارج از scope بک‌اند، هزینهٔ نگه‌داری بالا، و مدیریت مدل‌ها را دوباره‌پیاده‌سازی می‌کند |

## ۳. تصمیم

1. **`django-jazzmin==3.0.5`** به‌عنوان لایهٔ UI ادمین (ترتیب `jazzmin` باید **قبل** از
   `django.contrib.admin` در `INSTALLED_APPS` باشد؛ `E001` این را تضمین می‌کند).
2. **CSS/JS اختصاصی امیت** در `backend/static/admin_theme/`:
   - `css/emmett-admin.css` — توکن‌های برند، سایدبار، جدول‌ها، پیل‌های وضعیت، کارت‌های KPI.
   - `css/emmett-rtl.css` — **فقط** قواعد اسکوپ‌شده زیر `html[dir="rtl"]` (۱۰۶ قاعده)،
     شامل سایدبار، `.select2`، `#changelist`، `.object-tools`، `.submit-row`،
     `.inline-group`، `.ui-tabs` و اصلاح `text-align`/`direction`.
   - `js/emmett-admin.js` — رفتارهای کوچک UI (بدون وابستگی).
3. **هرگز RTL سراسری/جهانی نمی‌نویسیم**: تمام قواعد زیر `html[dir="rtl"]` هستند، بنابراین
   پنل انگلیسی از آن‌ها اثری نمی‌گیرد (قانون ۱۱ — RTL در سطح کامپوننت، نه CSS hack).
   استثنا فقط `admin/css/rtl.css` خود جنگو است که فقط در زبان فارسی بارگذاری می‌شود.
4. **فونت وزیرمتن خودمیزبان**: فایل‌های `vazirmatn-*.woff2` (وزن‌های مختلف) +
   `LICENSE` (SIL OFL 1.1) در `static/admin_theme/fonts/`. `use_google_fonts_cdn=False`
   و هیچ ارجاعی به `fonts.googleapis.com`/`cdn.jsdelivr.net` در قالب‌ها یا CSS نیست.
   `W006` هر ارجاع CDN را در `manage.py check` گزارش می‌کند.
5. **برند**: نشان‌نوشت `brand/emmett-wordmark.png` برای هدر/ورود، فاویکون اختصاصی،
   `site_title`/`site_header` ترجمه‌شده، و `topmenu_links` شامل «داشبورد» و
   «مشاهدهٔ سایت عمومی» (با `PUBLIC_SITE_URL`).
6. **UI Customiser جازمین در prod خاموش** (`show_ui_builder=False`) تا تم از هویت برند
   بیرون نزند؛ حالت روشن/تاریک با پیش‌فرض روشن (`ADMIN_DEFAULT_THEME_MODE`).
7. **branding پس از ready()**: `apps.core.apps.CoreConfig.ready()` تابع
   `apply_admin_branding()` را صدا می‌زند تا دارایی‌های CSS/JS بدون override قالب
   جازمین تزریق شوند (و در تست‌ها هم قابل بازرسی باشند).

## ۴. دلیل

- جازمین UI آمادهٔ بالغی می‌دهد (جدول، فیلتر، inline، modal، Select2 و UI Customiser) که
  بازنویسی آن‌ها در Django Admin خام هفته‌ها کار است، ولی RTL آن قابل اتکا نیست.
- نوشتن لایهٔ RTL **در سمت خودمان و اسکوپ‌شده** هر دو معیار را هم‌زمان برآورده می‌کند:
  RTL فارسی بدون شکستن LTR انگلیسی؛ و چون قابل شمارش/تست است (تعداد قاعده، اسکوپ‌بودن)
  می‌توانیم در تست‌ها از رگرسیون جلوگیری کنیم.
- خودمیزبانی فونت و ممنوعیت CDN الزام محصول برای هاست اشتراکی ایرانی و حریم خصوصی
  کاربران است (قانون ۶ و ۱۸)، و System Checkها آن را به یک قید ماشینی تبدیل می‌کنند.
- Unfold به‌خاطر نبود RTL رسمی رد شد: ریسک «شکستن همهٔ صفحات فارسی» بیشتر از سود ظاهری
  آن بود.

## ۵. پیامدها

**مثبت:** پنل هم‌هویت با سایت عمومی؛ RTL واقعی و قابل تست؛ بدون CDN و بدون build step؛
تم از طریق تنظیمات قابل تنظیم است (رنگ/حالت/جانمایی) و در تست‌ها قفل شده است.

**منفی/ریسک:** (۱) وابستگی به Jazzmin که در نسخه‌های آینده ممکن است ساختار قالب را عوض
کند؛ سه System Check (`E001` ترتیب اپ، `E003` مسیر قالب، `E004` دارایی استاتیک) و تست‌های
دارایی این ریسک را زود آشکار می‌کنند. (۲) لایهٔ RTL روی کلاس‌های AdminLTE سوار است؛ در
صورت ارتقای عمدهٔ قالب، فایل `emmett-rtl.css` باید بازبینی شود (در همین ADR ثبت شده).
