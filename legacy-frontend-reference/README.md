# بایگانی مرجع طراحی (Legacy Frontend Reference)

این پوشه اسکلت اولیهٔ React/Vite (محصول یک ابزار «Figma Make»، شامل shadcn/ui + Radix + MUI)
است که پیش از تصمیم معماری `ADR-0001` در ریشهٔ ریپو قرار داشت.

## وضعیت

**این کد مستقیماً در پروژهٔ نهایی استفاده نمی‌شود.** طبق `ADR-0001`:

> «فرانت فعلی React/Vite به‌طور کامل کنار گذاشته و در Next.js بازنویسی می‌شود؛
> کد مرده و بصری قابل استفادهٔ آن (رنگ/تایپوگرافی/موشن) به‌عنوان مرجع طراحی
> حفظ می‌شود، نه کد مستقیم.»

## چرا نگه داشته شده؟

به‌عنوان **مرجع بصری و محتوایی** برای فاز ۳ (Frontend Foundation) و فازهای بعد:

- رنگ‌ها و توکن‌های پایهٔ شادکن: `default_shadcn_theme.css`
- کپی/محتوای فارسی و انگلیسی موجود: `src/app/content.ts`, `src/app/pages/*`
- ساختار بخش‌های صفحهٔ اصلی (Hero, Manifesto, Divisions, Trust, ...): `src/app/components/*`
- مشخصات طراحی متنی (خروجی گفتگوهای طراحی قبلی): `src/imports/pasted_text/*.md`

## قوانین استفاده

- **کپی مستقیم کد ممنوع است** مگر با بازنویسی کامل در TypeScript strict و معماری
  Design System جدید (Atoms/Molecules/Organisms) تعریف‌شده در `frontend/`.
- `node_modules` این پوشه نباید نصب/اجرا شود؛ صرفاً مرجع خواندنی است.
- اگر محتوایی از اینجا به `frontend/` منتقل می‌شود، باید از فیلتر i18n (gettext/next-intl)
  و بدون رشتهٔ hard-code عبور کند (قانون ۹).
